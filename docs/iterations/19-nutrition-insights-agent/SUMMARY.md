## What Was Built

### Phase 1: Backend Nutrition Insights API

**Endpoint:** `GET /api/v1/nutrition/insights`
- Returns 3-period data (1d, 1w, 1m) in single call
- Aggregates nutrition stats using AnalyticsRepository
- Extracts user health profile (goals, allergies, conditions, targets)
- Prepares data structure for LLM processing
- Returns: periods (nutrition data) + health_profile + analysis (null until Phase 2)

**Files:**
- `src/schemas/nutrition_insights.py` (NEW) — Pydantic models
- `src/api/nutrition_insights.py` (NEW) — FastAPI endpoint
- `src/app.py` (MODIFIED) — Registered router

### Phase 2: LLM Nutrition Agent

**Agent:** `NutritionAgent` class using Claude Opus 4.7
- Calls Claude API with customized system prompt
- Analyzes nutrition patterns across 3 periods
- Generates analysis with:
  - Summary (1-2 sentences about nutrition status)
  - Strengths (2-3 things doing well)
  - Gaps (2-3 areas to improve)
  - Recommendations (3-5 specific foods with reasoning)
- Respects allergies and medical conditions
- Returns structured JSON response

**Features:**
- Goal-aware prompts (lean_out, gain_muscle, maintain, lose_weight)
- Past preference-based recommendations
- Robust JSON parsing (handles markdown-wrapped responses)
- Graceful error handling (returns None if LLM fails)

**Files:**
- `src/llm/nutrition_agent.py` (NEW) — Agent implementation
- `src/api/nutrition_insights.py` (MODIFIED) — Integrated LLM call

## Data Flow

```
iOS App (Insight Tab)
    ↓
View loads → .task { loadWeeklySummary(); loadNutritionInsights() }
    ↓ (2 parallel API calls)
    ├─ API: GET /api/v1/analytics/summary → WeeklySummaryResponse
    │   └─ Displays 4 line charts
    │
    └─ API: GET /api/v1/nutrition/insights → NutritionInsightsResponse
        ├─ periods: dict[1d, 1w, 1m data]
        ├─ health_profile: user goals, allergies, conditions
        └─ analysis: {summary, strengths, gaps, recommendations}
            ↑ Generated by Claude LLM Agent
            
Backend:
    1. Analytics API fetches nutrition data + health profile
    2. Calls NutritionAgent.analyze_and_recommend()
    3. Claude API call (~1-2 seconds)
    4. Parses JSON response into NutritionAnalysis
    5. Returns to iOS

iOS:
    Displays insights card when analysis != nil
    (Card hidden if analysis is None/null)
```

## Why User Hasn't Seen It Yet

**Most Likely Causes (in priority order):**

1. **App not rebuilt since Phase 3** 
   - Last phase completed with build fixes
   - Xcode cache might be stale
   - Need: Clean build (⌘K), then rebuild (⌘B)

2. **API not being called** 
   - `loadNutritionInsights()` might not execute
   - Silent error in async/await
   - Need: Check console logs for `[InsightViewModel]` messages

3. **API call failing** 
   - Backend endpoint might have issues
   - LLM call timing out (~2 seconds)
   - Need: Check server logs, verify `ANTHROPIC_API_KEY` set

4. **Card hidden due to nil analysis** 
   - LLM failed silently (parsed exception)
   - API returned without analysis field
   - Need: Print `viewModel.nutritionInsights` in console

5. **Models not matching** 
   - Codable decoding error on API response
   - Type mismatch in JSON parsing
   - Need: Check `APIClient.swift` for JSON errors

## Diagnostic Checklist

To troubleshoot why insights aren't showing:

### Step 1: Rebuild
```bash
cd NomNom-iOS
⌘ + Shift + K  # Clean build folder
⌘ + B          # Rebuild
⌘ + R          # Run on device/simulator
```

### Step 2: Check Console Logs
Open Xcode Console and look for:
```
[InsightViewModel] Loading nutrition insights...
[InsightViewModel] ✅ Nutrition insights loaded successfully
```

If you see errors instead:
```
[InsightViewModel] ⚠️ Failed to load nutrition insights: ...
```

### Step 3: Verify API Endpoint
Test from terminal:
```bash
curl -H "Authorization: Bearer YOUR_TOKEN" \
  http://localhost:8000/api/v1/nutrition/insights
```

Expected: JSON with `analysis` field populated

### Step 4: Check Backend Logs
```bash
# If running backend locally:
python -m uvicorn src.main:app --reload
# Look for: "[NutritionAgent] Generated analysis: ..."
```

### Step 5: Verify Environment
```bash
# Check ANTHROPIC_API_KEY is set
echo $ANTHROPIC_API_KEY

# If empty, set it:
export ANTHROPIC_API_KEY=sk-...
```
